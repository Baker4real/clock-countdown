# 办公室设备部署

使用 `Deploy-OfficeCountdown.ps1` 部署到 Tailscale 中的办公室设备。脚本只允许从干净且已推送的 `main` 部署，先检查 Tailscale 连通性，再生成 Windows 字节格式安装包并核对安装器 SHA-256 清单，最后通过受管 SSH helper 上传、执行安装器和回读运行状态。远端安装或验收失败时，会恢复原安装目录与计划任务。

硬约束：发起端与办公室设备都必须运行 PowerShell 7+（`pwsh.exe`）。部署脚本和安装器会拒绝 Windows PowerShell 5.1，不提供 fallback。

若部署失败，原本已使用 `pwsh.exe` 的计划任务会原样恢复；检测到遗留 `powershell.exe` 任务时，回滚会改为当前已验证的 PowerShell 7 路径，以保持该硬约束。

必须使用脚本生成的 Windows 工作树字节包，不要改用 `git archive`；在本项目的 Windows `core.autocrlf` 环境下，后者可能改变脚本字节并使安装器 SHA-256 校验失败。

部署默认保持既有 `settings.json` 原样。唯一允许的例外是旧版 schema v3 自动迁移到 schema v4，并新增空的 `notes` 列表；倒计时、显示精度、工资和上下班时间必须保持等价。任何其他设置变化都会视为验收失败并触发回滚。

部署前先做本地预检：

```powershell
pwsh -NoLogo -NoProfile -File .\Deploy-OfficeCountdown.ps1 -ValidateOnly
```

正式部署：

```powershell
pwsh -NoLogo -NoProfile -File .\Deploy-OfficeCountdown.ps1
```

脚本会将本次包和哈希证据保存到 `D:\Codex\.codex\run-evidence\clock-countdown-deploy\`。它不复制、打印或提交 SSH 密钥和办公室设备凭据；连接配置仅由本机受管 helper 提供。
